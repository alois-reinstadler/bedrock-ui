## Regression coverage and limits

Overlay cases verify removal of portal content, a still-connected shell, reachable search focus, subsequent pointer navigation and no page errors.

The block route now uses the same outgoing-data guard as the component route: SvelteKit may update an outgoing leaf with the incoming page data before teardown, so `data.block` must not be dereferenced unconditionally. The additional block regression checks this boundary and the retained document. This guard is based on the existing component-route lifecycle fix and code inspection; the integrated browser test is the runtime evidence.
