## Audit decisions and limits

- ClickableCard and SelectableCard already use native button activation and keep nested controls independent. Their state timing and animation tokens did not need changes.
- IconButton already uses the shared 44px tap-target utility and explicit accessible names. Its disabled anchor behavior is repaired centrally.
- Toggle's documented controlled `pressed`/`onPressedChange` path already updates native `aria-pressed`; no speculative binding API expansion was made.
- Pending/error semantics are covered by wave 1's AsyncButton lifecycle/geometry repair and production journey; this pass does not duplicate ownership.
- Focus correction is immediate and has no added transition, layout owner, animation duration or geometry change. It repairs the paint boundary rather than changing overflow or enlarging the card.
