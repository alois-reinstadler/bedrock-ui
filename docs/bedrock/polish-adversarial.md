The reversal sampler reads geometry after requestAnimationFrame callbacks via a zero-delay timer. Across 84 intervals: median **16.6ms**, p95 **25.4ms**, maximum **34.8ms**, **0 intervals above 50ms**. These are callback/measurement intervals on a shared container host, not a compositor trace or a device performance guarantee. Concurrent agents and host work can affect the numbers. There is no claim that width/height animation is compositor-only.

Observer accounting measures active subscriptions and detached targets, not garbage collection. The bookkeeping intentionally holds observer target references until unobserve/disconnect, so it cannot establish heap collectability or absence of unrelated retained closures. No heap-retention claim is made. Production warnings are recorded separately from page errors in the test attachment. The final run recorded neither.
